# Tekton a Indexer for blocks or documents

Tecton is a single runtime flexible indexer designed for indexing blocks of a dockument or documents.  
It contains a language specific fulltext and configuragble stemming and vector hmsw indexer.  
It can run as cli or web application.

> [!WARNING]
> The project is in early stage and can have breaking changes in the future.

## The indexer

### Index-fields
| Field |Type | Description | Optional | Autogenerated |
| ----- | --- | ----------- | -------- | ------------- |
| id | string | unique [ULID](https://github.com/ulid/spec) id (Universally Unique Lexicographically Sortable Identifier)  | true | [x] |
| date | i64 | Date | true |[x] |
| lang | string | language code 2 char | false | [ ]|
| tree | string | a path string for hierarchy like `/head/subhead` | false | [ ] |
| keywords | [string] | an array of keywords |false | [ ] |
| text | string | The text to index | false | [ ] |

### Text indexes
All 3 different text index are language specific. For each configured language a separate index is used.
Possible configurable languages are:  
`"ar", "da", "nl", "en", "fi", "fr", "de", "el", "hu", "it", "no", "pt", "ro", "ru", "es", "sv","ta", "tr"`

The default language is only ` "en" `

| index type | tokenizer | optional | enabled by default |
| ---------- | --------- | -------- | ------------------ | 
| fulltext | stop word (lang) | false | [ ]|
| stemming | stemming (lang) | true | [x] |
| vector | raw or stemming (lang) | true | [ ] |

The vector index is an Hmsw Hash based inder with confiragble n-gram, size and layers

> [!NOTE]
> All requirements for an inder are different, please test out the best result fore your requirement.  
A sample config is provided in the config folder. [config](./config/config.toml)



## Local execution

Build the project with

```sh
cargo install --path .
```
Copy the executable or execute from the building folder 
```sh
./target/release/tecton
```
